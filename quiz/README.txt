Online Quiz Management System
Console-based Core Java Project (BCA 1st Year)

HOW TO RUN
1. Install the JDK (Java 8 or higher).
2. Open a terminal / command prompt inside this folder.
3. Compile :  javac *.java
4. Run     :  java Main

FILES
Question.java      - stores one question, its 4 options and the correct answer
QuizManager.java   - keeps an ArrayList of 5 questions, runs the quiz, gives the grade
Main.java          - asks for the name, shows the result, asks to play again

CONCEPTS USED
Classes and objects, constructors, private variables with getters,
ArrayList, loops, if/else, switch, Scanner for input, exception handling (try/catch).
