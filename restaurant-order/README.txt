Restaurant Order Management System
Console-based Core Java Project (BCA 1st Year)

HOW TO RUN
1. Install the JDK (Java 8 or higher).
2. Open a terminal / command prompt inside this folder.
3. Compile :  javac *.java
4. Run     :  java Main

FILES
MenuItem.java       - one menu item (name and price)
OrderItem.java      - one line of an order (menu item and quantity)
OrderManager.java   - menu, current order, total bill and placed orders (ArrayLists)
Main.java           - shows the menu and takes input from the user

CONCEPTS USED
Classes and objects, constructors, private variables with getters,
ArrayList, loops, if/else, switch, Scanner for input, exception handling (try/catch).
